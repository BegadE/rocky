## Why build it?

A normal gallery organizes images by date. This experiment organizes them by place, making repeated walks and changing neighbourhoods visible over time.

The project page can hold a build log, design decisions, results, and links to the code. Documenting unfinished work is useful too—the question can be interesting even before the answer is complete.
